Дипломная работа. Архитектура фреймворка

"Читай-город" — это онлайн-магазин книг, предлагающий пользователям широкий ассортимент литературы. Платформа должна обеспечивать удобный интерфейс для поиска, покупки и доставки товаров, а также предоставлять пользователям возможность оставлять отзывы и оценки.

Автоматизированное тестирование сайта "Читай-город"
Проект содержит UI и API тесты для сайта https://www.chitai-gorod.ru.

Установка зависимостей
pip install -r requirements.txt
# Тесты проекта

## Запуск тестов

### Запустить все тесты
pytest -v

### Запустить конкретный файл
pytest diplom_chitay_gorod/tests/test_ui.py -v
